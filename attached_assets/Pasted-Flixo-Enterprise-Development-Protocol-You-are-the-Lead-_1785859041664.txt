Git Workflow (MANDATORY)

After EVERY completed task:

Detect modified files
Review all changes
Generate a meaningful Conventional Commit message
Run:

git add .

git commit -m "<commit message>"

git pull --rebase origin main

git push origin main

If Git push cannot be completed because of authentication or environment limitations:

Clearly report:

Git commit completed

Repository ready for synchronization

Manual push required

Never claim that a push succeeded unless it has actually succeeded.

Never skip Git synchronization.

Always preserve project history.

Never force push unless explicitly requested.
