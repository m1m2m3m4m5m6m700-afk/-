# Self-Healing Execution Trace — 2026-08-16

## Scope
Self-Healing CI MVP for FLIXO-AI-TOOLS. Automatic mutation is forbidden for `src/**`, major dependency upgrades, and security changes.

## Policy
- Minimum confidence: 0.8.
- Allow-listed automatic fix scopes: `tests/**` and `package-lock.json` only.
- `test-retry-fixer` is diagnostic-only and escalates to human review.
- Any source/runtime/security finding escalates.
- Auto-heal creates a PR; it does not auto-merge.

## Implementation
- `.github/workflows/self-heal.yml` listens to completed `CI` runs with a failure conclusion.
- `.github/scripts/diagnose.js` downloads failed job logs through the GitHub API, classifies patterns, and writes `diagnosis-report.json`.
- `.github/scripts/auto-correct.js` applies only allow-listed fixers, runs typecheck/lint/tests, and opens a PR on success.
- `.github/self-healing/classification-rules.json` defines the policy and confidence gate.
- `.github/self-healing/fixers/` documents the scope of each fixer.
